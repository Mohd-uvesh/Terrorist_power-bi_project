# 📊 Terrorism Data Analysis (Power BI)  

## 📖 Overview
A Power BI project analyzing terrorism data to identify patterns, regional impacts, and frequency of incidents.
This Power_Bi project shows Terrorist attack and death all over the world since 1970-2021.  

## ⚙ Tech Stack  
- Power BI  
- Dataset: Global Terrorism Database  

## 🚀 How to Run  
1. Download the .pbix file from this repository  
2. Open it in Power BI Desktop  

## 📊 Output  
- Interactive dashboard with filters  
- Insights on regions, attack types, and casualties
